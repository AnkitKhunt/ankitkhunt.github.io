# Ankit Khunt — Academic Website

A responsive, static academic portfolio built with HTML and CSS for GitHub Pages.

## Publish on GitHub Pages

1. Create a **public** repository named `ankitkhunt` (or another name you prefer).
2. Upload `index.html`, `style.css`, and this `README.md` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then click **Save**.
6. Wait for the deployment to finish. The project site URL will look like:
   `https://YOUR-GITHUB-USERNAME.github.io/ankitkhunt/`

## Before sharing publicly

- Review all biography and research text for accuracy.
- Add links to your complete publication list, ORCID, Google Scholar, ADS, and CV.
- If adding a CV PDF, place it in the repository and link to it from `index.html`.
- Replace any placeholder sections with your preferred contact details.
- Keep your Google Sites website online until you have checked the new site.

## Files

- `index.html` — website content and navigation
- `style.css` — visual design and responsive layout

No build tools or frameworks are required.
