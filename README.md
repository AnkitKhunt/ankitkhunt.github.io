# Ankit Khunt — Academic Research Website

A responsive, multi-section academic portfolio for GitHub Pages, built with plain HTML, CSS and a small amount of JavaScript.

## Files
- `index.html` — all page content, navigation, hyperlinks and metadata
- `style.css` — responsive design
- `assets/compact-star.svg` — original, scalable compact-object illustration
- `assets/profile-placeholder.svg` — placeholder image; replace with your own portrait
- `assets/ak-mark.svg` — favicon and monogram

## Update your existing GitHub Pages website
Your repository is `AnkitKhunt/ankitkhunt.github.io`, so its live address is `https://ankitkhunt.github.io/`.

1. Download and extract this ZIP.
2. Open your repository's **Code** tab.
3. Upload the new `index.html` and `style.css`, replacing the existing files.
4. Upload the entire `assets` folder, preserving its folder name and file names.
5. Commit the changes to `main`.
6. Wait for the GitHub Pages deployment to finish, then refresh the live site.

Keep the assets folder beside `index.html`; the relative links depend on that structure.

## Add your real portrait
Replace `assets/profile-placeholder.svg` with a portrait file, for example `assets/ankit-khunt.jpg`. Then, in `index.html`, change:
`<img src="assets/profile-placeholder.svg" ...>`
to:
`<img src="assets/ankit-khunt.jpg" alt="Ankit Khunt">`

## Before publishing
- Verify email and every personal/profile link.
- Add your complete, verified publication list and co-author details.
- Add a CV PDF (for example `assets/Ankit_Khunt_CV.pdf`) and link it from the page.
- Add confirmed ORCID, Google Scholar, ADS and institutional profile URLs when available.
- The research descriptions are drafted from your public Google Sites biography and prior details. Please proofread for scientific and biographical accuracy.
- The portrait is intentionally a placeholder, not a real image of you.

## Editing
All content is in `index.html`. Search for section names like `RESEARCH DIRECTIONS`, `PUBLICATIONS`, or `CONTACT` to find the relevant content.
